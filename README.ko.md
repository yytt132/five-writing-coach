# Five Writing Coach — 한국어 안내

글을 하나의 막연한 “문장력”으로 평가하지 않고, **독자에게 어떤 변화를 일으키려는가**에 따라 다섯 가지 모드로 분류하고 평가하는 글쓰기 코칭 Skill입니다.

## 다섯 가지 글쓰기

| 유형 | 독자에게 일으키려는 변화 | 대표 장르 |
|---|---|---|
| 문학적 글쓰기 | 경험하게 한다 | 소설, 에세이, 서사 |
| 전문가의 글쓰기 | 검증·납득하게 한다 | 논문, 전문보고서 |
| 설명자의 글쓰기 | 이해하게 한다 | 과학기사, 교양서, 강의 |
| 설득자의 글쓰기 | 판단·행동을 바꾸게 한다 | 논쟁적 칼럼, 사설, 연설 |
| 실용적 글쓰기 | 정확히 행동하게 한다 | 이메일, 공문, 안내문, 매뉴얼 |

전통적인 **서사·묘사·설명·논증**은 글을 구성하는 방식이고, 위의 다섯 가지는 글의 목적을 분류합니다. 두 체계는 경쟁하지 않고 함께 사용할 수 있습니다.

## 평가 방식

각 글은 기본적으로 100점으로 평가합니다.

- **공통 역량 40점**: 목적 적합성, 구조와 흐름, 문장 명료성, 독자 적합성
- **유형별 역량 60점**: 각 유형에 맞는 6개 기준 × 10점
- **치명적 오류 검사**: 점수와 별도로 수행
- **수사학적 진단**: 필요할 때 Logos / Ethos / Pathos / Kairos 분석
- **성장 피드백**: 가장 큰 강점, 병목, 수정 우선순위, 다음 훈련 목표

### 중요한 원칙

**한 글의 점수는 유형에 따라 달라질 수 있습니다.**

예를 들어 강력한 논쟁적 칼럼이 설득자의 글쓰기에서는 90점 이상일 수 있지만, 실용적 글쓰기에서는 50점대일 수 있습니다. 이는 모순이 아니라 목적이 다르기 때문입니다.

## 대표적인 장르 배치

### 과학기자의 글쓰기

기본적으로 **설명자의 글쓰기**에 속합니다.

> 설명자의 구조 + 전문가의 정확성 + 문학적 전달력

### 논쟁적 칼럼

기본적으로 **설득자의 글쓰기**에 속합니다.

> 설득자의 논증 + 전문가의 근거 + 설명자의 이해 가능성 + 필요할 경우 문학적 장치

## Logos / Ethos / Pathos / Kairos

이 네 요소는 100점에 중복 가산하지 않고 **보조 진단 레이어**로 사용합니다.

| 유형 | 특히 중요한 요소 |
|---|---|
| 문학적 | Pathos |
| 전문가 | Logos + Ethos |
| 설명자 | Logos + Ethos + Pathos (+ Kairos) |
| 설득자 | Logos + Ethos + Pathos + Kairos |
| 실용적 | Kairos + Logos |

- **Logos**: 주장이 말이 되는가?
- **Ethos**: 화자와 판단을 신뢰할 수 있는가?
- **Pathos**: 독자가 왜 중요한지 느끼는가?
- **Kairos**: 지금 이 독자와 상황에 적절한가?

## 추천 사용법

```text
이 글을 Five Writing Coach 기준으로 평가해줘.
목표 유형: 설명자의 글쓰기
100점 평가 + 치명적 오류 검사 + Logos/Ethos/Pathos/Kairos 진단을 해줘.
그리고 이번 글의 최대 약점 하나와 다음 글에서 훈련할 기술 하나를 정해줘.

[글]
```

목표 유형을 지정하지 않으면 글의 목적과 독자를 바탕으로 주 유형을 판별합니다.

## 장기 훈련에 사용하는 법

이 Skill의 핵심 목적은 단발성 점수가 아니라 **반복 가능한 글쓰기 훈련**입니다.

각 글마다 다음을 기록하면 성장 추적이 가능합니다.

1. 목표 유형
2. 총점 및 세부 점수
3. 가장 강한 역량
4. 가장 약한 역량
5. 치명적 오류 여부
6. 다음 글에서 훈련할 단 하나의 기술

점수를 누적하면 “글을 잘 쓰는가?”보다 구체적으로 “설명 순서는 좋아지고 있지만 예시를 만드는 능력은 정체되어 있다”와 같은 진단을 할 수 있습니다.
